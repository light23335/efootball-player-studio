## 安装和使用

面向 Android 8.0 及以上的 ARM64 手机；APK 同时含 x86_64 用于模拟器。
已验证 Android 15 的 4 KB 环境和 Android 16 的 16 KB 系统兼容模式。
16 KB 设备仍依赖系统兼容模式，不能保证所有机型：游戏运行时使用 Python 3.12
字节码，对应的部分
NumPy/cryptography 原生依赖仍为 4 KB 构建。参见 Android 官方说明：
https://developer.android.com/guide/practices/page-sizes#16-kb-backcompat-mode
首次允许系统安装此应用，打开后在“导入游戏 APK”页从系统文件选择器依次选择
原版或个人主 APK、配套离线资源 APK。文件需下载到手机本地，保留其位置和文件权限。
应用不会复制整份输入 APK；提取的数据库和资源缓存在应用私有目录。

手机顶部下拉菜单可切换全部工作区；实时预览默认收起，点击“展开预览”查看。
头模支持单指旋转、双指缩放和平移。搜索框独占一行，位置与卡种筛选并排显示。
已检查 320/360/412 像素竖屏、平板和横屏，共 60 项页面布局。

制作游戏包时留足空间：资源缓存约 4～5 GB；生成主包和离线资源包还需要对应
输出文件的空间。建议开始前至少留出 15 GB，具体需求会在操作前检查。
导出时选择系统“保存到”位置，文件复制完成会提示。后台长任务显示通知；
不要强行停止应用、清理其数据或移除输入文件。首次资源准备和签名可能较慢。

每台手机首次生成独立游戏签名；首次安装改签后的游戏不能直接覆盖另一个签名
的版本。游戏主包与配套资源包应在同一台手机生成，使用同一个签名。
升级球员工坊时覆盖安装，保留应用数据；不要卸载旧版。重要工程请先导出
.efproject 备份。此分享 APK 内没有任何私人的球员、脸模或签名。

新主包可从软件重新导入；若游戏底层接口发生变化，软件会明确拒绝不兼容写入，
保留当前数据库和工程。不能保证任意未知游戏版本都无需适配。

## 从源码构建（Windows）

需要 JDK 21、Python 3.12、Gradle 8.13、Android SDK（platforms;android-36、
build-tools;35.0.0、NDK 28.2.13676358）。设置 JAVA_HOME、ANDROID_SDK_ROOT，
把 gradle 和 python 加到 PATH。首次构建需联网获取 Maven/PyPI 依赖。

解压源码后在 PowerShell 运行：

```powershell
./build_android.ps1
```

脚本在临时 ASCII 路径构建，避免 Android 插件不支持中文工程路径。可通过
-Stage 指定空的 ASCII 构建目录，-Core 指定公开桌面核心源码；源码包自带 core。
结果复制到 output/app-release-unsigned.apk；正式发布需用自己的发布密钥配合
zipalign 和 apksigner 签名。发布密钥不包含在源码或分享包中。

src/debug 下是测试探针和只读测试文档提供器，**release 不包含它们**。
原版二进制测试素材不随源码分发。测试脚本在 tests/，公开核心在 core/。
第三方许可见 THIRD_PARTY_NOTICES.md。
