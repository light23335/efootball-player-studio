球员工坊 V15 · 1.9.0

新增功能（PC / Android 同步）：
1. 导出与游戏设置：查看导出文件，确认后清除全部导出 APK、工程、图片、模型及报告；保留工程、我的球员、素材和签名。不会自动删除用户导出内容。
2. 导出后：安卓可直接打开系统安装器（需允许本应用安装未知来源应用）；PC 打开文件所在位置。也可继续保存到指定目录。
3. AI 组别：设置当前组别、积分 / 评分、本轮场次及胜平负。保存后生成游戏 APK；首次覆盖启动应用一次，之后正常累计，不反复重置。组别 10–4 使用本轮积分，3–1 使用评分。
4. 非原生骨架头模：提示后使用原生头骨中性绑定继续生成，原始 GLB 不修改。非原生骨架的面部权重不会直接套入游戏，请检查头颈位置及实际显示。
5. 顶部“导出工程”：可多选“我的球员”与当前工程，合并为 .efproject。其他人可导入合集；不同内容的相同永久身份另建槽位，保留本机原工程。
6. 开屏使用声明：完全免费，仅供个人娱乐、学习交流，禁止盈利；素材权利归原权利人，本软件与游戏官方无关联。
7. 球员资料中设置游戏已有的庆祝动作编号；留空沿用源球员，0 为默认。
8. 修复安卓竖屏卡面预览拉伸。横屏与 PC 保持原布局。
9. 球衣背后名字与卡面显示名单独设置；留空沿用球员姓名。卡面预览优先显示俱乐部徽标，游戏内徽标逻辑保持现状。

保留修复：126 张中国版卡允许加入卡包，其余 134 张原包禁用卡继续过滤。旧卡包跳过无效成员并保留抽取记录；报告列明跳过名单。小头像按原生 UI 贴图与专用动画槽位导出。
生成的游戏 APK 完整保留原版 120 帧设置模块，由玩家自行选择帧率，实际效果受设备性能限制。

使用与升级：
Windows x64：完整解压后运行球员工坊.exe。更新保留原完整 data 目录，不要用空白分享版 data 覆盖自用数据。
Android 8.0+ ARM64 / x86_64：同签名覆盖安装，保留应用数据。不要先卸载旧版。
分享包只含编辑器、运行工具和数据库索引，不含个人工程、原版资源缓存、游戏 APK、个人签名或玩家存档。
修改后需重新生成游戏 APK，再同签名覆盖安装游戏；已经生成的旧包不会自动更新。生成包已经过签名及资源读回检查，实际游戏效果仍需验收。
