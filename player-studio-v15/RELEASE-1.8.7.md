# 球员工坊 V15 1.8.7

修复游戏内小头像只有人物、卡面背景发黑的问题，Windows 与 Android 同步。

- 小头像背景自动使用大卡面的背景图层。更换预设、系列背景或自选背景后，预览和下一次生成的 APK 一起更新。
- “从大图裁切”和“独立图片 / 原版小头像”仍保留各自的人物来源、缩放和位置；选择独立头像不会丢掉卡面背景。
- 动画卡面使用约 0.8 秒处的静态帧（较短视频取时长的三分之一）作为小头像背景；原游戏的大卡面视频保持原样。
- 小头像预览与 APK 原生纹理共用合成代码，不烘焙总评、姓名、队徽等游戏动态文字和标志。大卡面人物纹理保持原样。
- 缺失背景资源时明确报错，避免静默生成黑底头像。视频帧缓存复用，裁切调整不会反复解码。

验收：100 项 Python 回归中 99 项通过、1 项因缺少可选旧样本跳过。范戴克的真实头像读取原包比较：旧头像 51% 区域透明；新头像已合入卡面背景，大小卡分别引用正确纹理，大卡面人物逐像素不变。实际 EXE 的预览像素与原生小头像纹理相同。雷电 x86_64 上已覆盖更新安卓版并验证系统视频取帧和 512×512 小头像合成。游戏内显示效果仍待用户安装重生成的游戏 APK 验收。

升级工坊不会自动改动已安装的游戏。保留现有 data，重新生成包含这些球员的游戏 APK，并沿用原有签名覆盖安装，才能更新游戏内小头像。无需重新导入人物图或调整现有裁切。

分享 ZIP / APK 为纯软件，不包含个人球员、签名私钥、游戏 APK 或原版资源缓存。Android 8.0+ ARM64 / x86_64 兼容范围与此前版本相同；本轮未新增实体 ARM64 手机验证。
