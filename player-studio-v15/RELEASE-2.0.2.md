# 球员工坊 2.0.2 · 本地版

“我的球员”新增文件夹：新建时可批量勾选已有球员，建好后仍可使用“添加已有球员”继续添加。支持搜索、翻页勾选、重命名和移出文件夹。

每名球员只保存一份工程；加入其他文件夹会移动分类。移出或删除文件夹只取消分类，保留球员工程、素材和游戏数据。删除球员仍需单独确认。

长传好手：长传、传中及挑传直塞的出球前摇缩短 20%，方向、仰角及球速随机扰动降低 40%。更强的直塞前摇效果仍优先，不叠加。

PC 与安卓功能同步，覆盖更新保留已有工程和签名。本轮仅提供本地软件，不上传 GitHub。

文件夹功能更新后即可使用。长传好手的新效果须重新生成并安装游戏 APK 后生效。
