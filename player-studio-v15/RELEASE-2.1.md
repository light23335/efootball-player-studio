# 球员工坊 V17 · 2.1（本地版）

PC 与 Android 同步更新，本轮不提交 Git，也不上传 GitHub。

## 签名与安装引导修订

- 安卓修订构建为 2.1-android.2（201001）：资源 APK 与游戏 APK 均直接使用共用签名实现，接收 prepared、consume 参数；保留流式摘要复用、低空间消耗及独立验签，修复 unexpected keyword argument 'prepared'。PC 签名实现本身无需修复。
- 两端安装选项改为“共存模式”和“工坊更新模式”，分别说明“工坊版”共存包、保留原游戏、非共存工坊包及仅已有原版资源包的使用情况。首次生成使用哪种模式，后续更新就继续选择同一种模式。
- 根据当前导入库的实际 APK 包名、工坊记录和本机签名自动推荐模式并说明原因。成功生成后记住该来源和签名的首次模式。已有共存包继续推荐共存；其他设备签名的工坊包推荐共存。仍可手动选择，并在生成中保持模式不变。
- PC 提示安卓版生成的包、安卓提示 PC 版生成的包，跨端继续修改时引导使用共存模式。共存不会取得另一设备的签名私钥，不能据此保证覆盖保留另一签名的存档。

- **安卓导入工坊派生包**：读取器分别支持原版 UE4 v11 PAK 和工坊生成的 v3 动态卡面 PAK，修复 `cardstudio_100_P_10_P.pak`、`cardstudio_content_100_P_10_P.pak` 的“未适配的原版 PAK 页脚”。不转换或重编码视频，校验索引、路径、条目头和实际视频内容。原版 v11 的读取路径保留，索引失败后不缓存半份结果。
- **AI 空增能槽**：除常规 `0` 外，从当前原生增能表识别“空占位类型且全部已核实能力效果为零”的记录，不固定为编号 136。两个占位类型字段须一致，已登记的自建增能不作为占位。当前捕获包的 443 条记录中，该类非零占位只有 136。
- **补槽规则保持**：每名 AI 对手球员有空槽时只补一项，按位置随机选择当前原生表中有效的原版常驻增能。不新增条件增能或自建增能，原有条件增能保留；两槽都空时仍只补一个，不保证两个图标都亮。
- **旧对手快照**：对旧快照中漏补的空占位补一次，并同步实际参数、增能列表、球员总评和战术评分。已经补过的球员不重复补，暂停或重试不重抽。参数恢复保留已分配的常驻增能，名单身份和玩家已拥有球员不变。

保留 2.0.6 的过期 DIY 卡号校验、编译缓存、UCAS 与签名导出优化，以及此前装备、AI、动态卡面和安卓界面功能。

安卓工坊同签名覆盖更新，保留工程；覆盖后可重新尝试导入之前失败的包。AI 补槽修复须重新生成并覆盖安装游戏 APK 才会写入游戏。PC 自用版仅替换程序，保留 data、library、素材和签名。

已完成本地回归及故障 PAK、名单副本的核对；未安装或运行修改后的游戏，实机表现待用户测试。
