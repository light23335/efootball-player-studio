# 球员工坊 V17 · 2.1.3 本地版

PC 与 Android 同步优化导出；本轮不上传 GitHub。

- 卡包设计的“添加自建球员”支持按姓名、卡面名、永久身份搜索及文件夹筛选，每页显示 24 人。可添加整个文件夹，实时读取该文件夹的全部球员，不受搜索词或分页限制；跳过已添加球员，保留原有权重，超过卡包 2000 人容量时整次拒绝而不部分添加。

- 原始 CPK 只读取一次，同一导出内共享经过验证的 WESYS 解码结果，缓存按实际字节匹配且有内存上限，任务结束释放。最终球员表仍绕过缓存独立解码核对。
- 同语言的增能及技能文本合并为一次解析。更新值相同时，保留原文本、填充和压缩字节，不再重建和压缩；编号、名称和占用冲突检查保留。
- 相同 CPK 按内容、CRC、长度和压缩参数复用 DEFLATE 结果，激活及实时更新两个路径各写一份，分别校验实际成品。
- 视频缓存命中后直接读取缓存 ZIP 内的已验证文件区间，不再提取约 499 MiB 来源包或复制约 501 MiB 命中结果。未压缩来源直接引用文件区间；压缩来源仅在缓存未命中、需要检查重建时解压落盘一次。复制时再次检查 CRC、SHA-256 和大小。
- 缓存引用在导出期间保持打开，清理及淘汰跳过正在使用的内容。视频最多占公共缓存预算的一半，为卡面、脸模和压缩块留出空间；过大视频包正常生成但不缓存。
- 替换资源读回与实时更新业务检查共享从最终 APK 实际读出的摘要，小型控制 JSON 同次读取。保留完整独立验签、两份 CPK 核对、资源 CRC/大小/SHA-256 及发布清单检查。
- 导出报告新增独立阶段耗时、CPK 解码命中、重复压缩复用及视频中间写入字节数。计时覆盖工作线程至注册表保存，明确不包含报告序列化及临时文件清理。

PC 自用版仅替换程序，保留工程、数据库、素材及签名；安卓同包名、同签名覆盖更新，不要先卸载。优化用于后续生成，不需为性能更新重新安装已有游戏。

本轮不改游戏 AI、技能、抽卡、装备、脸模或存档规则，不改 XI 与 PC Offline。验收包括本地回归及真实 APK 导出、签名、资源检查；未运行游戏实测。桌面测试不能当作手机整包提速倍数。
