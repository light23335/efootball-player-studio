# 球员工坊 V15 1.8.6

本版同时更新 Windows 免安装版与 Android 独立版。

- “新建球员”立即建立独立永久身份和保存槽位；新建前保存旧球员。切换球员清空撤销记录，异步载入原版模板不会写入已经切走的槽位。
- 模型页新增比赛装备：球鞋型号、随季节 / 短袖 / 长袖，逐球员保存。当前 V15 原库识别 53 个球鞋型号。
- 卡包支持上传 PNG / JPG / WebP 封面、缩放和水平 / 垂直取景，保存后随选中卡包写入 APK。封面资源包含校验值，游戏本地图片服务同时保留原版图片来源。
- APK 数据导入支持工坊个人自建主包与配套改签资源包。再次生成时按永久身份更新，保留未选中的已有球员、教练、卡包和原生资源；引擎兼容性检查继续生效。
- 原版头模预览使用完整近景 LOD。自制头模的张嘴 / 闭眼检查和辅助定位物体不写入导出 GLB；实际蒙皮保留。源模型无面部权重时，关闭保护不会自动生成权重。
- Android 修复梅西高清纹理读取失败：可选高清 mip 从 `.uptnl` 读取，普通 mip 从 `.ubulk` 读取。已在雷电 x86_64 上覆盖安装，读取普通及特殊版本梅西，三个模型均成功嵌入 5 / 5 材质；另对 73 张梅西纹理完成解码。

验证包括：94 项 Python 回归（93 通过、1 项因缺少可选旧版样本跳过）、Android 可选纹理回归、实际 EXE 启动、桌面和 390 像素手机界面、槽位切换、GLB 导出，以及个人包导入后更新 1 名球员并读回保留其余 3 名球员、卡包、装备和签名。

装备、封面在生成 APK 后的实际游戏表现仍需游戏内验收。高画质手臂修复沿用 1.8.5 测试方案，尚未在本轮进行游戏实战验收。Android 实机 ARM64 兼容性未新增验证。

升级已有工坊时直接覆盖程序文件 / 覆盖安装 APK，保留 data。分享 ZIP / APK 为纯软件，不含个人球员、脸模、私钥、游戏 APK 或游戏资源缓存。已有游戏包需要使用新版工坊重新生成，才能包含本次编辑。

纹理存储格式参考：[CUE4Parse EBulkDataFlags](https://github.com/FabianFG/CUE4Parse/blob/master/CUE4Parse/UE4/Assets/Objects/EBulkDataFlags.cs)。
