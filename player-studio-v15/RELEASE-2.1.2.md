# 球员工坊 V17 · 2.1.2 本地版

PC 和 Android 同步优化 APK 生成过程。本轮不上传 GitHub。

- 每次生成只解压一次 ARM64 引擎，并核对完整 SHA-256；技能、手柄、AI、显示等接口随后读取同一临时文件。保留接口校验、原补丁顺序和错误定位。
- UCAS、教练容器与合并后的视频包采用文件型替换，分块计算 CRC、SHA-256、资源清单及最终读回校验，避免把整个大资源复制进 Python 内存。
- 合并视频包按实际来源内容、视频映射和内容、编译版本缓存。已完全包含所需视频时直接复用原内层包；缓存损坏重新生成，视频重名冲突仍会报错。未改动的内层 ZIP 条目直接复制压缩数据。
- 大文件缓存共用已有容量预算和清理入口，PC 默认 4 GiB、Android 默认 1 GiB；超过预算不缓存，不影响正常导出。
- 保留完整 APK 独立验签、资源 CRC/大小/SHA-256 读回检查和实时更新清单检查。

同签名更新 Android 工坊可保留现有工程；PC 只替换程序，保留 data、library、素材和签名。优化作用于后续生成，不需因本次性能更新重装已有游戏。

速度受设备、储存、头模规模及缓存命中影响；桌面局部测试不能当作手机整包提速倍数。本轮未安装或运行游戏验收。
