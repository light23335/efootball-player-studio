# 球员工坊 2.1.7（本地修正版）

修复“所选原 V17 游戏未装内容增量，但当前工坊库已装增量”时的头像绑定遗漏。此前自动补齐已写入球员表、头像文件和内容清单，美术安装器却重新读取原 APK 的旧清单，导致依赖新增绑定的球员显示灰色头像或占位队徽。

- PC、安卓共用的美术安装器改用合并后的生效内容清单，原包、已装增量的工坊包及连续增量写入均使用相同流程。
- 导出前核对内容清单与实际注册表的每个编号及绑定值，签名后再次从成品 APK 读取并核对。遗漏或内容不同会停止交付，报出受影响球员编号。
- 增加卡尼吉亚、格罗索的专项回归；在独立 ARM64 模拟中核对头像名称及原生脸型查找编号，并检查原始回退与栈恢复。
- 保留 2.1.6 的增量／全量写入、未修改球员隐藏及已导入内容缓存自动补齐功能，无需保留原始增量 ZIP。

本轮仅本地交付，未上传 GitHub。软件更新保留工程、素材及签名。旧游戏 APK 不会自行改变，需要用修正版工坊重新生成；另外提供保留本次原有球员、教练、卡包和游戏设置的同签名测试 APK。未替用户安装或运行游戏，实际头像显示由用户验收。
