# 球员工坊 V17 · 2.1.1 热修版

PC、Android 同步修复部分旧数据在游戏启动时触发 `'NoneType' object has no attribute 'get'` 的问题。

- 旧 AI 比赛快照、对手资料为 SQL NULL、JSON `null` 或无效结构时，先保留原始记录，再移出无效的私有对手快照，按没有有效当前比赛继续初始化。下一次准备比赛时正常生成对手。
- 卡池中的空白、`null`、非对象或无法解析的卡牌记录先备份，再从抽取定义及对应卡包引用中隔离；持有球员、培养、经验、技能和组别进度保持。被本次实装选中的自建卡可从有效设计重新建立定义，不重复发放已持有球员。
- 有效卡号核对、过期 DIY 迁移及异常对手过滤继续保留，未取消防止总评 40 的检查。正常原版和工坊快照保持原样；重复启动不反复处理已隔离记录。
- 备份位于游戏数据库的 `meta`：快照使用 `personal_ai_catalogue_snapshot_backup_v1:` 前缀，异常卡池原文使用 `personal_catalogue_invalid_v1:` 前缀。相同比赛编号的不同异常内容分别保留。
- 延续 2.1 的安卓签名修复、PAK 读取、空增能槽识别、安装模式自动引导、编译缓存和现有功能。安卓版构建为 `2.1.1-android.1`（201100）。

PC 退出工坊后覆盖程序，保留 `data`、`library` 和签名；安卓同签名覆盖更新，不要先卸载。**更新工坊后，需要重新生成并覆盖安装游戏 APK，启动修复才会生效。** 软件不会直接改写已经安装的游戏。

本次公开发布 V17 PC、安卓及对应源码，不包含个人工程、游戏安装包、原版资源缓存或签名私钥。XI 分支和 PC Offline 项目保持原样。已验证构造的异常数据库与正常旧存档兼容；反馈设备的实际失败堆栈尚未取得，不能保证所有同文案报错均来自这一处。
