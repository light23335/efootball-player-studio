# 球员工坊 V17 · 2.0.1 本地修订版

- 长传好手的出球前摇缩短改为 30%，方向、仰角及球速随机偏差仍降低 40%。与手术刀直塞共同生效时取更强效果，不叠乘。
- AI 随机组队在新建和复用对手时均检查实际能力及显示缓存。异常展示缓存按真实能力重新计算；能力损坏时仅从同一卡牌记录恢复，保留比赛、阵型、教练、球员身份及玩家存档。新增修复诊断与原快照备份。
- 已验证两类损坏快照的修复，以及原版 V17 准备比赛和重入流程。用户反馈的偶发开场总评 40 尚无原始日志，不能断言该偶发原因已完全定位，仍需游戏复测。
- 教练列表的“用于预览”和“查看三维头模”直接显示该教练当前配置；自建教练使用已上传的 GLB，原版教练使用已保存的替换或原模型。移除独立测试工作区入口。
- 新建教练、没有独立头模的复制教练自动使用资源中的默认教练头模，可直接导入自己的 GLB。默认模型与 APK 编译使用相同配置；需先准备完整游戏资源。
- APK、球员、教练、增能、卡包封面、原生资料表、工程素材与客户端 PNG／GLB 导出失败时，显示对象、步骤和原始原因。共用资料出错时标明资料文件，不将错误归到刚处理完的球员。

PC 与 Android 同步，保留既有数据和签名。游戏修改需重新生成游戏 APK 后生效。本版仅本地交付，不上传 GitHub。
