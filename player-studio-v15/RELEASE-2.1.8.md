# 球员工坊 2.1.8（本地视频导入修正版）

- 安卓视频转换改为 Java 内处理像素，移除逐帧 PNG、跨语言像素传输和 Pillow 往返。优先连续解码一次，共享大小卡所需的时间点；不支持可读 YUV 的设备回退为共享缩放取帧，仍不使用 PNG。
- 修复交错、共享 UV 缓冲区的写入：只写有效采样，不清零另一通道或填充区。统一输出 BT.601 NTSC、有限范围、SDR 的 YUV 与编码参数；处理源视频旋转、裁切及常见 BT.709 输入。
- 转换结果按视频内容与大小卡参数分别缓存。重复导入直接复用；仅修改小卡裁切时可以复用大卡。缓存命中仍核对资产内容。
- 动态视频导入纳入后台任务、安卓工作状态；显示取帧／编码、帧数、编码器名称及硬件／软件属性，支持取消。取消、失败或切换工程不会替换原卡面。
- 安卓可对可定位的本地视频保留读取权限并直接读取；需要复制的文件提供方在复制前检查已知大小，并在复制过程中执行 512 MiB 上限。
- PC 同步独立缓存、任务进度和取消；PC 的 FFmpeg 编码流程保留。

旧版已经导入的偏色视频无法恢复被覆盖的色度，请重新选择源视频导入，并重新生成游戏 APK。当前版本仅本地交付，不上传 GitHub。未在手机编码器或游戏实测，成品颜色与设备兼容性由用户检查；不承诺提速倍数。

球场和锦标赛仍在独立开发，本次视频修正版不包含未完成功能。覆盖更新保留已有工程、素材与签名。
