# 球员工坊 V17 · 1.9.7.1

PC 免安装版与 Android 独立版同步更新。分享包不含个人球员、存档、签名密钥、游戏 APK 或原版资源缓存。已有工程与素材保存在原 data 中，更新时请保留 data、library 和签名。

- 实体手柄：在“导出与游戏设置”连接 USB / 蓝牙手柄并按任意键识别。支持按手柄录入单键或最多三个按键的组合，也可手动选择。提供游戏默认和 FC 常用预设；可改左右摇杆与右摇杆方向。FC 预设射门 B、长传 X、紧密盘带 RB、冲刺 RT、搓射 RB+B、超级取消 LT+RT。组合优先，松开即释放；扳机轴和方向键按键型手柄均有处理，冲刺扳机保留原始力度。
- 自定义帧率上限 15–999 FPS，前台锁定目标；修正雷电在 x86 内核运行 ARM64 游戏时，原 FPS 启动检查跳过的问题。
- 渲染分辨率目标最高 4K，保持设备宽高比，最长边不超过 3840。实际画质与帧率受设备、屏幕及游戏渲染器限制。
- 大小卡面在显示期间恢复播放；原版小卡优先使用小卡动画，缺少时链接同系列大卡背景。保留退出页面后的原生回收逻辑。
- 修正绑定原游戏球员 ID 后，私人卡编号被误用于查询卡面系列而丢失大图背景的问题。
- 修正“我的球员”中已有拉拉纳等自制工程被当作未完成空槽位、无法进入编辑的问题。
- 修正心有灵犀风格重复转换，以及第四个教练能力槽错读。2019 Klopp 对应双人逼抢 A 与突破传球 D。
- AI 比赛风格的写入位经原生代码核对，原来的中文名称有误；现按游戏名称显示。已保存勾选不会自动互换，若之前按旧名称配置，请重新核对后生成 APK。
- 新增技能的名字与说明同步写入游戏文本，包括不同身高的健步如飞变体。

FC 预设按移动端默认操作区分：原生 RT 是冲刺与紫射，RB 是控制射门，LT 是紧密盘带与对位。RB+B 单独输出控制射门组合；不会作为 RT+射门触发紫射。辅助施压 / 控制射门单键设为 LT，可继续自行调整。

参考：[官方移动端手柄操作说明](https://www.konami.com/efootball/en-us/page/mobile_controller)。

## 使用手柄改键

1. 打开工坊的“导出与游戏设置”，连接手柄，再按任意键。
2. 选择游戏默认或 FC 常用预设；点击“按手柄录入”，按下需要的键并全部松开。需要时手动调整或清空绑定。
3. 勾选“将实体手柄改键写入游戏 APK”，点击“保存游戏设置”。可在同页设置分辨率和帧率。
4. 重新生成并安装游戏 APK。游戏中所有已连接手柄使用同一套映射；仅更新工坊不会改变已生成的游戏。

软件界面使用 Xbox / PlayStation 对应的按键位置。没有识别为标准布局的设备可以手动选键。默认未启用改键与画质、帧率覆盖。
