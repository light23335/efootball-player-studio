# 球员工坊 · Player Studio

Windows 与 Android 源码，当前版本 **1.9.5**，适配 73efootball V16。安装包和源码压缩包见本仓库 Releases。

## 本轮更新

- 修复普通点击被页面根节点的导航属性误判为模式切换，导致所有页面反复重绘、输入失焦的问题。检查了 15 个工作区。
- 新手导航分组稳定展开，只有球员编辑需要先读取球员；“从已有球员复制”移入“我的球员”，不会修改原球员。
- 自建球员删除必须确认，保留备份与素材，清理卡包引用；最多 10,000 名，分页浏览。
- 教练预览支持中英文名称及卡包搜索。
- 共享增能库最多 10,000 项，可跨球员复用到任意一槽。按本次使用情况分配原生编号，保留旧编号；第一槽使用 8 位兼容别名。原生增能表为 10 位编号，不能在同一 APK 直接使用 10,000 个不同原生编号。
- 安卓直接安装前检查游戏与对应资源的包名依赖和签名，允许原版与 DIY 各自配套共存；PC 检查选定文件。成功切换新导入库后清理旧导入库和对应缓存，保留个人工程、素材与签名。
- 桌面窗口关闭事件保存当前编辑并退出后台，刷新可重连；大工程使用未保存差异避免关闭消息过大。保留之前所有编辑、共存安装及可选 GitHub 更新提醒功能。

## 源码目录

`player-studio-v15/` 是沿用历史名称的当前 V16 共用核心、Windows 主程序和 Web 界面。`player-studio-android/` 是 Android Java、Python、原生纹理解码及构建脚本。

首次克隆后使用 Python 3.12 运行 `python prepare_source.py` 还原压缩的默认数据库。Windows 构建依赖见 `requirements-build.txt`，Android 构建见其 README 与 `build_android.ps1`；第三方工具须从官方来源自行准备，来源和许可证见各目录说明。

源码与分享包不含个人球员、照片、脸模、工程、存档、签名私钥、游戏 APK 或原版缓存。运行时需自行导入有权使用的文件。
