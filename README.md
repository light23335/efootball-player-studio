# 球员工坊 V17 · 1.9.6

PC 与 Android 同步更新。新版编辑器保留已有工程、素材和签名；本次发布为干净分享包，不含个人球员、游戏 APK 或原版资源缓存。

- 适配 V17 的两层原版美术绑定，保留 V17 自带的全部 10 条模型路线。兼容共用相同原生接口的 V16.1。
- 修正教练增能的原生编号，覆盖全部 26 项能力。正确区分两项能力增能和两项心有灵犀，避免将心有灵犀误当成增能。
- 教练编辑增加心有灵犀：仅选择原包已有的 32 种组合，分别修改核心球员与关键球员的位置、比赛风格；复制原教练时读取并保留。原生同名占位组合按类型和组合编号区分。
- 球衣号码优先读取原包球员资料，缺少时读取原生阵容表，并显示来源。原包没有号码时明确提示。
- 每名自建球员增加“绑定原游戏球员 ID”。勾选后使用与对应原版球员相同的人物身份，保留独立自建卡号；不勾选使用独立人物身份。修改、重复导出和分享工程不会覆盖原版球员。
- 技能名称以原游戏简体中文文本为依据，旧名称保留为搜索别名。
- 重炮攻门：凌空抽射或蓄力达到 50% 的射门，射门偏差降低 20%。
- 掠地瞬击：普通射门也能触发，保留原生低于 50% 蓄力与其他动作条件。
- 健步如飞：≤175 cm 为爆发加速，176–185 cm 为掌控加速，≥186 cm 为漫长加速。在原生加速计算中分别调整低速、高速阶段，不额外增加永久速度属性。
- 长传好手：空中传球的动作前摇缩短 12%。这些新增效果使用固定默认值，无强度配置项。

已进行数据库原始记录保留、重复导出身份、心有灵犀条件编码、真实 ARM64 指令和原版安装工作器隔离检查。没有启动模拟器进行游戏内验收；新增技能的比赛手感及动画表现仍需实际游戏验证。未知原生接口会停止对应实装。

更新方法：PC 解压到原编辑器目录并保留 data、library；Android 使用同签名 APK 覆盖安装。游戏 APK 需重新生成才包含本次修改。原有 V15 专用版单独保留。


源码首次克隆后运行 `python prepare_source.py` 还原默认数据库。PC 源码位于 player-studio-v15，Android 源码位于 player-studio-android；目录名为历史名称。
