# 球员工坊 · Player Studio

电脑版（Windows）与安卓版的共用源码。当前开发版本为 1.9.4，面向 73efootball 离线版；该轮界面与共存功能仍在完成验证，不作为正式安装包发布。

## 目录

- `player-studio-v15/`：Windows 主程序、共用 Python 核心、Web 界面和测试。目录名沿用历史名称，当前代码适配 V16。
- `player-studio-android/`：Android Java、Python 适配、原生纹理解码及构建脚本，默认读取同级共用核心。

不包含个人工程、球员照片、脸模、游戏安装包、存档、原版资源缓存或签名私钥。运行与生成 APK 需要使用者自行导入有权使用的游戏及配套资源。

## 本轮功能

新手首页、完整导航切换、可搜索详细教程；首页清理导出缓存；读取已安装的兼容原版 / DIY APK（Android）；共存的游戏与配套资源；首次生成两包、后续默认只生成游戏；新建槽位与覆盖模板的提示、覆盖前备份。非强制 GitHub 更新提示尚在接入。

共存版为独立应用与存档。保留存档覆盖安装要求包名、签名和版本号兼容；本软件不能获得原作者签名，也不能直接读取其他应用的私有数据。

## 准备源码

1. 使用 Python 3.12，先运行 `python prepare_source.py` 还原压缩的默认数据库。
2. Windows 依赖见 `player-studio-v15/requirements-build.txt`。第三方工具二进制不在源码仓库中；工具来源与许可证见各目录的 `SOURCE.txt` 和 `THIRD_PARTY_NOTICES.txt`。从相应官方来源准备这些工具后，再按原构建脚本打包。
3. Android 需要 JDK 17 或更新版本、Android SDK 36、Gradle 及 NDK。构建方法见 `player-studio-android/README.md` 和 `build_android.ps1`。发布签名必须由使用者自己创建并保管，不能使用其他人的私钥。
